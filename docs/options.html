Output transport

ZIP is the portable download because the retained builders create multiple files and directories. The archive contains the original relative tree and is not presented as a new document format. The same completed tree can also be written to a selected folder when the browser exposes the File System Access API.

Static artifact strategy

The reproducible Docker build uses the pinned .NET 10.0.400 SDK and WebAssembly workload, tests and publishes the runtime, removes redundant precompressed copies, and builds Vite. Generated runtime files are staged under ignored web/public/engine and copied into the static web/dist artifact. Build output is not source-controlled. A prebuilt Vercel workflow still requires Stage 6 validation; no function or runtime secret is configured.
