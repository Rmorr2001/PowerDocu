PowerDocu browser adapter status

Canvas HTML slice demonstrated

The browser UI accepts a standalone .msapp, transfers its bytes to a dedicated Web Worker, runs the retained C# AppParser and Canvas HTML workflow in .NET WebAssembly, and downloads the generated directory tree as a ZIP. There is no application backend or serverless function.
